# Desktop Idle Heroes — прототип

Idle-RPG, которая живёт полоской внизу рабочего стола. Герой сам бьёт волны монстров,
клик мышкой ускоряет атаки, с монстров падают предметы разных тиров, их можно
надевать, затачивать (+1…+10) и сливать (3 → 1 следующего тира).

Движок: **Godot 4.7**, рендер Compatibility (нужен для прозрачного окна).
Мир 3D, персонажи — 2D-спрайты (2.5D).

## Запуск

- В редакторе: F5. Чтобы увидеть режим «на рабочем столе», отключите встраивание игры
  во вкладке **Game** (кнопка *Embed Game on Next Play*), иначе окно будет обычным.
- Выход из игры — кнопка «Выход» (у окна нет рамки).
- Сохранение: `%APPDATA%\Godot\app_userdata\Desktop Idle Heroes\save.json`.
  Удалите файл, чтобы начать заново.

### Отладочные аргументы (после `--`)

```
Godot.exe --path . -- --autotest --class=mage --timescale=4
Godot.exe --headless --path . -- --autotest --selftest --quit-after-seconds=3
```

`--autotest` — отдельное свежее сохранение и авто-создание героя,
`--selftest` — проверка логики предметов/сохранений (печатает `SELFTEST OK`),
`--open-inventory`, `--screenshot=путь.png`, `--timescale=N`, `--quit-after-seconds=N`.

## Структура

```
data/                 ← ИГРОВЫЕ ДАННЫЕ (.tres), редактируются в инспекторе
  classes/            классы героя
  monsters/           монстры и боссы
  items/              шаблоны предметов
assets/sprites/       картинки (heroes, monsters, items, fx)
assets/ui/theme.tres  общий стиль интерфейса
scenes/
  main.tscn           корень: экран создания ↔ бой
  creation/           создание героя, карточка класса
  battle/             сцена боя + WaveManager
  actors/             Actor (база) → Hero, Monster; полоска HP
  effects/            снаряд, всплывающий текст, полёт лута
  ui/                 HUD, инвентарь, ячейка предмета
scripts/
  autoload/           Database (реестр данных), GameState (прогресс+сохранение),
                      DesktopWindow (окно-полоска и сквозные клики)
  data/               классы ресурсов: CharacterClass, MonsterData, ItemBase
  items/              Item, LootGenerator (дроп), ItemUpgrader (заточка/слияние)
tests/self_test.gd    автопроверка
tools/generate_placeholders.gd  генератор временных спрайтов
```

Каждая сущность — отдельная сцена со своим скриптом. Сцены общаются сигналами,
данные лежат в `.tres`, баланс — константами в начале скриптов.

## Как добавить контент

- **Класс**: скопируйте `data/classes/warrior.tres`, поменяйте `id`, имя, статы, спрайт.
  Если задать `projectile_texture`, класс будет стрелять снарядами.
- **Монстр**: скопируйте `.tres` из `data/monsters/`. `min_wave` — с какой волны появляется,
  `is_boss` — только на каждой 10-й волне.
- **Предмет**: скопируйте `.tres` из `data/items/`. `allowed_classes` пустой — подходит всем,
  `drop_weight` — относительный шанс выпадения (1 — обычно, 0.5 — вдвое реже).
  Слоты героя: шлем, плечи, броня, ноги, оружие, ботинки, аксессуар.
- **Реликвия армии** (`slot = 7`, 6 слотов в инвентаре): статы `army_power`, `army_attack`,
  `army_defense`, `training_speed`, `upkeep_reduction` — усиливают армию замка, а не героя.
  Бонусы уходят на сервер (`POST /api/hero {armyGear}`); предметы пока считает клиент,
  поэтому сервер урезает сумму до `armyGearCaps` в `server/src/config.ts`.

Новые файлы подхватываются автоматически, код трогать не нужно.

### Умения

У каждого класса 3 умения (открываются на 1, 5 и 10 уровнях). Они применяются сами,
если включён переключатель «Авто», или вручную: клик по кнопке либо клавиши **1, 2, 3**.

Умение — это `.tres` в `data/skills/` (имя, иконка, перезарядка, уровень) + **эффект**:

| Эффект | Что делает | Пример |
|---|---|---|
| `StrikeEffect` | сильный удар/снаряд по цели, опционально урон по области вокруг неё | Мощный удар, Огненный шар |
| `AreaEffect` | урон по области вокруг героя или вокруг цели | Вихрь, Метеор |
| `MultiShotEffect` | залп снарядов по нескольким врагам | Залп |
| `BuffEffect` | временно +урон / +скорость атаки / +броня, лечение | Боевой клич, Магический щит |

Новое умение: скопируйте `.tres` из `data/skills/`, поменяйте числа и добавьте его в
список `skills` нужного класса. Новый *тип* эффекта: унаследуйтесь от `SkillEffect`
(`scripts/skills/`) и переопределите `execute()`.

### Таланты

Окно талантов — кнопка «Таланты» или клавиша **T**. За каждый уровень после первого
даётся 1 очко. У класса 3 ветки по 4 ряда; ряд N открывается, когда в ветку вложено
N × 3 очка (`points_per_row`). Сброс возвращает все очки за золото (50 × уровень),
кнопку нужно нажать дважды.

Дерево класса — один файл `data/talents/<класс>_talents.tres`, таланты в нём —
вложенные ресурсы (редактируются в инспекторе). У таланта: ветка, ряд, макс. ранг и
список бонусов `StatModifier` (значение за 1 ранг). В описании `{value}` / `{value2}`
подставляются автоматически с учётом ранга.

Типы бонусов (`StatModifier.Stat`): урон, здоровье, броня, скорость атаки, шанс и сила
крита, урон и перезарядка умений (всех или одного — поле `skill_id`), сила клика,
золото, опыт, шанс дропа, регенерация, вампиризм. Новый тип бонуса: добавить значение в
enum, иконку в `assets/sprites/talents/` и применить его в `GameState.get_hero_stats()`
(или там, где он нужен).

### Потребности героя

Сытость, Жажда, Бодрость (0–100, `data/needs/`) падают только во время боя.
От 70 и выше дают бонусы, ниже 30 — небольшие штрафы. Смерти от голода нет.
Еду и воду герой берёт со склада королевства сам. Когда Бодрость на нуле, герой уходит
отдыхать: волны на паузе, пока шкала не заполнится. Можно отправить отдыхать вручную
кнопкой «Отдых».

### Королевство

Окно — кнопка «Замок» или клавиша **K**. Ресурсы: еда, вода, дерево, камень и **казна** (золото замка).
10 зданий (`data/buildings/`): Ратуша (склад, казна, лимит уровня остальных зданий),
Ферма, Колодец, Лесопилка, Каменоломня (производство), Таверна (отдых, замедление
голода и жажды), Кузница (урон), Казармы (HP, броня), Конюшня, Рынок (казна).
Одна стройка за раз, у каждой свой таймер.

**Замок живёт на сервере** (защита от читов): ресурсы, стройка, найм и содержание армии
считает только сервер, в том числе пока игра закрыта. Клиент (`KingdomState`) — зеркало:
показывает состояние, плавно «догоняет» производство между опросами и отправляет действия.
Без связи с сервером замок доступен только для просмотра. После запуска показывается
«Пока вас не было…» — разница между последним сохранённым и текущим состоянием с сервера.

**Казна** пополняется Ратушей и Рынком. Золото героя (с монстров) можно внести в казну
кнопкой «Внести в казну»: лимит взносов копится со временем и растёт с уровнем героя
(золото героя считает клиент, поэтому сервер ограничивает объём).

Новое здание: скопируйте `.tres` из `data/buildings/` — стоимость, рост цены, время,
производство (`produces`, `production_per_level`) и бонусы `modifiers` за уровень.

### Армия замка

Вкладка «Армия» в окне королевства. У каждого замка своя армия (`KingdomState.army`, зеркало сервера).
Отряды (`data/units/`): Ополченец, Копейщик, Лучник (Казармы 1–3 ур.), Рыцарь (Конюшня).
У отряда: атака, защита, места в армии, содержание (еда/мин), стоимость и время обучения.

- Вместимость армии дают Ратуша, Казармы и Конюшня (`army_capacity_per_level`).
- Найм — очередь обучения (до 5 заказов), идёт и оффлайн; отмена возвращает ресурсы.
- Армия ест еду со склада. Нет еды — сила армии −50%, солдаты не умирают.
- Бонусы: скорость обучения (Казармы), сила армии (Кузница, Конюшня) и захваченных зон.
  Таланты героя на армию сервера пока не влияют (герой считается на клиенте).
- Армия замка защищает его от набегов; солдат можно взять с собой на карту.
Бонусы талантов, зданий и потребностей (и армии) складываются в `GameState.get_bonus()`.

### Мировая карта (онлайн)

Кнопка «Карта» или клавиша **M** — окно раскрывается на большую часть экрана.
Нужен запущенный сервер (cd server && npm start, подробности — [server/README.md](server/README.md)).

- 10 000 зон (100×100); чем ближе к центру, тем сильнее нейтральная армия и больше бонус.
- «Армию из замка →» — отправить солдат из армии замка к герою на карту (герой в замке).
- Клик по соседней зоне → «Атаковать / Занять / Напасть». Поход идёт по таймеру.
- Зона без гарнизона, когда вас там нет, захватывается другим игроком без боя.
  Если вы в зоне (или там гарнизон) — будет бой. Проигравший теряет армию, герой — в замок.
- «Оставить гарнизон» — защитить зону, пока герой идёт дальше.
- Бонусы захваченных зон работают в игре (`GameState.get_bonus`).
- **Набег на замок** соседа: поход дольше обычного, защитник видит его заранее (красная линия
  на карте, «Карта (!)», сообщение). Защищают армия замка и герой с армией, если он дома.
  Победа — 20% ресурсов сверх неприкосновенных 100, защитник теряет половину армии и получает
  щит на 4 ч. Поражение — армия нападавшего гибнет. Замок захватить нельзя.
- **Защита новичка** — 72 ч без набегов; снимается, если игрок сам нападёт на другого игрока.
- **Повтор боя** — кнопка «▶» у отчёта (новый бой при открытой карте показывается сам): толпы
  сходятся, солдаты падают по потерям из отчёта, в конце — итог и добыча. Исход считает сервер,
  повтор только показывает его (`scenes/world/battle_replay.gd`). Солдатики пока рисуются кодом;
  картинку отряда для боя можно задать в `battle_sprite` (`data/units/*.tres`, вид сбоку, лицом вправо).

Клиент: `scripts/autoload/world_service.gd` (запросы и кэш), `scenes/world/` (карта).
Проверка связи: сервер с `MARCH_SECONDS=2 DEV_SPEED=100 DB_PATH=data/test_world.db`, затем
`Godot.exe --headless --path . -- --autotest --world-test --quit-after-seconds=90`.
## Арты из ChatGPT

Замените PNG в `assets/sprites/` на файлы с **тем же именем** — или укажите новый
спрайт в `.tres`. Размер в пикселях не важен: высоту в мире задаёт `sprite_height`.

Пример промпта: *«2D game sprite, full body fantasy archer, side view facing right,
transparent background, feet at the bottom edge, no shadow, consistent style»*.

- Персонаж смотрит **вправо** (монстры отражаются автоматически).
- Прозрачный фон, ноги у нижнего края, без лишних полей.
- Маленькие картинки (≤128 px) рисуются как пиксель-арт, большие — сглаженно.

Вернуть заглушки: `Godot.exe --headless --path . --script res://tools/generate_placeholders.gd`.

## Анимации персонажей

Исходные ленты (кадры в ряд, из ChatGPT) — `assets/sprites/heroes/<класс>/source/<класс>_<анимация>.png`.

1. Нарезать ленту (фигуры целиком, общая область, ноги на одной линии; рост — как у idle):
   `Godot.exe --headless --path . --script res://tools/slice_animation_strip.gd -- <исходник> res://assets/sprites/heroes/warrior/warrior_<анимация>.png --match=res://assets/sprites/heroes/warrior/warrior_idle.json`
   (для самой idle — без `--match`).
2. `Godot.exe --headless --path . --import`
3. Собрать анимации: `Godot.exe --headless --path . --script res://tools/build_sprite_frames.gd -- res://assets/sprites/heroes/warrior warrior`
   → `warrior_frames.tres` (указан в `data/classes/warrior.tres`, поле `sprite_frames`).

Имена анимаций: `idle`, `walk`, `rest` (фоновые, зациклены), `attack`, `hurt`, `death`, `victory` и анимации
умений (`SkillData.animation`, у воина — `power_strike`, `whirlwind`, `war_cry`). Скорость и зацикливание —
в `tools/build_sprite_frames.gd`. Каких анимаций нет — те просто не играются.
## Интерфейс из сгенерированных листов

Исходники листов — `assets/ui/source/` (как прислали), нарезка — `assets/ui/<группа>/`,
подключение — `assets/ui/theme.tres` (StyleBoxTexture с отступами 9-slice).

1. Нарезать лист (убирает светлый фон, находит элементы, уменьшает до пиксель-арта):
   `Godot.exe --headless --path . --script res://tools/slice_ui_sheet.gd -- res://assets/ui/source/<лист> res://assets/ui/<группа> <префикс>`
2. Измерить отступы 9-slice:
   `Godot.exe --headless --path . --script res://tools/measure_ui_margins.gd -- res://assets/ui/<группа>/<файл>.png`
3. Если импорт падает с «No loader found» — тема ссылается на ещё не импортированные картинки:
   временно уберите строку `theme/custom` из `project.godot`, выполните `--import`, верните строку.

Варианты панелей в теме: обычная `PanelContainer` (окна), `PanelSmall` (нижний HUD, подсказки),
`PanelHeader` (верхняя полоса карты) — задаются через `theme_type_variation`.
`PanelSection` — рамка разделов (окно инвентаря). Цветные кнопки: `ButtonGreen`, `ButtonRed`, `ButtonBlue`
(перекрашены из обычной кнопки: `tools/recolor_ui.gd -- <исходник> <результат> <оттенок>`).

Окно инвентаря собрано по макету `assets/ui/source/ui_inventory_mockup.webp` из листа
`ui_inventory.webp` (детали — `assets/ui/inventory/`); иконки предметов — из `ui_items.webp`.
Окно королевства — по макетам `ui_kingdom_buildings_mockup.webp` / `ui_kingdom_army_mockup.webp` из листа
`ui_kingdom.webp` (детали — `assets/ui/kingdom/`); иконки зданий, ресурсов, отрядов — из `ui_kingdom_icons.webp`,
фигурки солдат для повтора боя — из `ui_units_battle.webp` (`battle_sprite` в `data/units/*.tres`).
Нарисованную на рамке иконку можно стереть: `tools/clear_ui_interior.gd`.
Общие элементы, собираемые в коде (плашки, заголовки разделов, стили из картинок) — `scripts/ui/ui_styles.gd`.
Окна в полосе рабочего стола должны помещаться по высоте в 340 px (`DesktopWindow.WINDOW_HEIGHT`).
